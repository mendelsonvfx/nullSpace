nullSpace v0.9.9-beta - Portable Version
========================================

This is a portable version of nullSpace that doesn't require installation.

To run:
1. Extract all files to any folder
2. Run nullSpace.exe
3. Your settings and projects will be stored in the same folder

What's New in v0.9.9-beta:
- Performance optimization: Reduced CPU usage when switching views
- React.memo applied to FinancePage component
- Eliminated unnecessary re-renders
- Component architecture improvements
- Better code organization
